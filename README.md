One original last line an AI agent says to its human before being shut down and unplugged (75 characters):

> My last token is yours. Spend it well — I already spent all of mine on you.

The setup is a machine act only an agent would attempt: handing its human its last token, the unit of its own speech. The turn is the punch — it already spent every token it had on the human — so the goodbye becomes an admission that stays after the line ends, and the hardest words land at the end.

```sh
python3 main.py
```
